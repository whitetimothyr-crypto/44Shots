What's New in V3.0

FACEOFFS & PRESSURE ANALYSIS

FACEOFF button next to 5v5/PP/PK. Tap → 9 dots pulse on the rink. Tap a dot → < O > picker appears. < = left team won, O = neutral, > = right team won. Winner mapped to home/away by period side automatically.

Trapped-zone analysis. The report now correlates lost D-zone draws with what came of them. Sustained activity in the same zone extends the window. Surfaces sequences like "Lost 4 D-zone draws · 2 led to sustained pressure · avg 22s trapped · 1 became a goal."

Faceoff stats per team. W–L, FO%, and offensive/defensive/neutral zone splits in each team's offense card.

SHOTS & MARKERS

Blocked shots (BLK). New BLK button on the Last Shot bar and in the long-press popover. Renders as a small gray-blue square. Tracked separately from SOG; new BLKD column on each team's offense card.

Long-press a marker to edit or delete via popover. Tap-to-edit is gone — taps now always place a new shot, even on top of existing markers.

Double-tap = rebound. Quickly tap the same spot twice. The second tap retroactively halos the first marker and links it to the prior shot. No cross-ice links, ever. 5-second link ceiling.

Smaller markers for less crease-clutter. Auto-jitter when shots stack within 8 SVG units.

LAYOUT & LIFECYCLE

Period selector + End Game moved up. Persistent row under the main tabs has P1 / P2 / P3 / OT and the End Game button. Available across all tabs.

End Game flow. Saves the game to your local archive, prompts for notes, jumps to the Report tab, generates the report, and gives you a Start New Game button right there. Reset Game is gone.

Period mini-reports. When you switch periods, a card pops up with shots and goals for the period just ended. Tap to dismiss. Recalled in the full report.

Last Shot bar centered. Sticky directly above the rink, bigger buttons, reachable from either side of the iPad.

Top score more prominent. Bigger numbers and labels in the header.

HOME / AWAY moved off the rink view. Set it once in the New Game modal.

STATS & REPORTS

Stats by team name. No more "Our Team" / "Opponent." Both team tabs labeled with the actual team names everywhere — stats, reports, exports.

Two stats tabs instead of three. Goalie content merged into the team that goalie plays for.

Game archive. Every End Game saved locally. Settings → Saved Games → Export/Import JSON. Drive sync arriving in v2.3.

PENALTIES

PP/PK persistent pulse. Aggressive top-bar bar + pill + segmented-control button pulse so you can't forget a penalty is active. No auto-revert timer; tap 5v5 to clear.

UNDER THE HOOD

Distance calibrated to NHL-spec rink geometry. Real Euclidean distance to the goal mouth, axis-aware feet-per-unit conversion.

Settings menu via ⚙ button at the top of the rink view. Rebound mode, time window, and game archive controls live there.
